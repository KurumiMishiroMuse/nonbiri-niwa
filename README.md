# のんびり庭育成

家のそばの小さな庭で、花をのんびり育てるゲームです。
ランキングも課金も失敗もありません。眺めて、水をやって、ゆっくり育てるだけの知育ゲームとして公開しています。

## あそびかた

- お店で種を買います。お店に並ぶ種は毎日6種類が入れ替わります（いつもある種＋季節の種＋ランダムな種＋たまに珍しい種）。
- 買った種は手元に残り、畑の空いている場所に植えて育てます。
- 花は時間とともに 育ちます。水をやると少し早く育ちます。
- 育った花を収穫すると「はっぱ」がもらえます。はっぱで新しい種や、庭の飾りを買えます。
- 花は全部で21種類。組み合わせや収穫を重ねると、新しい花が見つかることがあります。「花のずかん」で集めた花を確認できます。
- 最初からやり直したいときは、日誌の一番下にある「夢から覚める」から初期化できます。

## セーブについて

- セーブデータは遊んでいるブラウザの中（localStorage）に保存されます。アカウント登録は不要です。
- 別の端末や別のブラウザでは、庭は引き継がれません。それぞれの場所で、それぞれの庭が育ちます。

## 技術メモ

- 単一の HTML ファイル（index.html）だけで動作します。外部通信・外部フォント・外部画像は使っていません。
- お店の品揃えは端末の日付から決定的に決まるため、その日は誰が開いても（同じ端末では）同じ顔ぶれになります。
